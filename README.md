# DSH Split Sidebar

在上半屏看对话，在下半屏跑终端。点会话右上角的**水平分屏图标**，输入框下面就有一个独立工作区。收起时，整列高度都还给会话。

## 一边对话，一边做事

- **开几个真正独立的终端。** 第一次展开会打开终端。点标签旁的 **＋**，就能在一个终端跑开发服务，在另一个看日志。各个终端使用 DSH 的原生进程和当前会话的工作目录。收起分屏或切走会话后，再回来可以接着输入。鼠标中键可直接关闭标签，也可以点悬浮时出现的关闭按钮。关闭终端标签会结束对应进程。
- **两处终端用同一套字体。** 下方直接使用 DSH 右侧的原生终端组件。修改终端字体或字号，两处一起生效。使用 Ghostty 的用户可以一键导入本机外观。首选字体缺少 Powerline 分隔符时，两处终端都会依次尝试本机符号字体和随包附带的四个字形。
- **一边找文件，一边看预览。** 右侧面板宽度达到 400 像素时，可以同时看目录树和文件内容，直接点下一个文件。
- **拖到一段视频中间就能看。** 音视频按需分段读取，可以直接拖动进度条。实测一个 38.4 MB 的 WAV，跳到 32 MiB 处请求 1 KiB，只传回了这 1 KiB。侧栏使用浏览器解码。遇到特殊编码，可用本机播放器打开，系统列出 IINA 时优先选择 IINA。图片保留宿主的缩放控件，PDF、文本和表格沿用 DSH 各自的预览。
- **需要时才占资源。** 合上的分屏占用 0 像素。分屏代码首次展开时加载，终端模拟器第一次选中终端时才加载。隐藏终端会拆下屏幕渲染器并保留进程。浏览其他会话时不会替它们创建终端。

## 位置与设置

点会话右上角横向的侧栏按钮，展开或收起底部终端。按钮沿用 DSH 右侧栏图标，旋转了 90°，悬停会显示用途。底部滑动沿用 DSH 的时长与缓动，“减少动态效果”开启时直接切换。可以拖动上边缘调整高度，也可以聚焦分隔线后按上下方向键。

打开 **插件 → DSH Split Sidebar** 查看终端设置，也可以在右侧新标签页的 **更多工具 → 设置** 打开同一组控件。字体和字号写入 DSH 的终端偏好，在 DSH 通用设置里修改也会同步。

**从 Ghostty 导入**读取当前主机的字体、字号、前景色、背景色和水平、垂直内边距。在 macOS 下按 Ghostty 的逻辑尺寸导入字号，取 DSH 支持的 10–20 像素整数。字体名称对应的字体需要安装在运行桌面客户端的设备上。右侧终端使用导入的上边距，底部终端将上边距限制在 4 像素以内，给首行留出更多空间。修改 Ghostty 后可再次导入。光标、行高、程序的 ANSI 配色和键位由 DSH 原生终端控制。导入仅在点击按钮时读取一次，插件不记录配置原文。字体大小的单位见 [Ghostty 配置说明](https://ghostty.org/docs/config/reference#font-size)。

| 插件配置 | 默认值 | 用途 |
| --- | --- | --- |
| `showDock` | true | 提供会话标题右侧的水平分屏按钮 |
| `autoSplit` | true | 宽面板默认并排显示文件树和预览 |
| `nativePlayer` | true | 提供本机播放器入口 |
| `streaming` | true | 对已授权的音视频启用分段传输 |
| `chunkKiB` | 256 | 单次读取上限，16–1024 KiB，并遵守宿主更低的限制 |

## 安装

在 DSH 插件管理器里通过 GitHub 安装 `github:qso/dsh-split-sidebar#v0.3.1`。本地开发可克隆仓库、运行 `npm ci --ignore-scripts`，再选择该目录安装。已在 macOS 的 DSH Desktop 0.2.2-rc.5 验证。原名为 DSH Dockline，已有旧版的用户请使用新版替换旧包，避免两个侧栏同时加载。

希望进一步加快长会话切换和图片预览，可以同时安装 [DSH Better Performance](https://github.com/qso/dsh-better-performance)。

## 隐私与兼容性

媒体通过当前 DSH 连接读取。只有经宿主认证的所有者能申请短期播放地址，每个分段校验源文件版本。插件不上传媒体、终端输出或会话。大图片、PDF 和办公文件受宿主预览上限约束。MKV、AVI、MOV 的播放能力取决于实际编码。本机 IINA 单独安装。终端进程寿命也受 DSH 关闭和宿主自身的回收策略约束。

布局灵感来自 [DSH Better Sidebar](https://github.com/omdsh-dev/DSH-better-sidebar)。底部复用 DSH 已注册的侧栏终端，插件包无需附带第二份终端模拟器。

## 开发

使用 Node.js 22.19 或更高版本。运行 `npm ci --ignore-scripts`、`npm test` 和 `npm pack --dry-run`。MIT 许可证。
